# UI 设计工具 Prompt 模板参考

当目标工具是 Figma、Motiff、MasterGo、即时设计等 UI 设计工具时，按以下模板组织 prompt。

这个模板的核心设计原则是**每个 section 独立可用**。用户会逐个 section 复制到 AI 设计工具中生成，所以每个 section 必须内联所有必要的设计 token（色值、字号、间距），不能依赖"参见上文"。

## 整体方向 Prompt 模板

整体方向必须拆成独立子章节，用 ### 标题分隔。配色和字体用表格组织（因为表格比 bullet list 更容易被设计工具解析，也更容易对照检查）。

```
### 产品概述
产品：[一句话描述]
用户群体：[目标用户]
设计风格：[2-3 个风格关键词]
参考风格：[可选，类似 XXX 的风格]

| 边框色 | #XXXXXX | 分割线、输入框边框 |
```

## 单页面 Prompt 模板

每个 section/页面的 prompt 必须**自包含**——内联本 section 用到的色值、字号、间距，让用户可以单独复制使用。

```
页面名称：[名称]
页面用途：[用户来这个页面做什么]
入口场景：[用户从哪里进入此页面]

布局：
[描述整体布局，如"全宽横向区块，内容区最大宽度 1280px 居中"]
[用文字描述各区域的位置关系和大小比例]
[标注本区域的背景色 #XXXXXX，内边距 XX px]

内容细节：
- [逐一描述每个元素，内联色值和字号]
  例："主标题：48px Bold #0A1F44，行高 1.2，最大宽度 600px"
  例："CTA 按钮：高度 52px，圆角 8px，背景 #22C55E，白色文字 16px Medium"
- [对于列表/表格，列出列名和数据格式]
- [对于表单，列出字段名、类型、占位符]

示例数据：
[提供 3-5 条真实感的示例数据，包含差异性]

状态：
- 空态：[无数据时的提示文案和插图描述]
- 加载态：[骨架屏 / 旋转图标]

交互：
- [描述关键交互，内联动效参数]
  例："鼠标 hover 时卡片上移 4px，阴影加深至 0 4px 16px rgba(0,0,0,0.12)，过渡 200ms ease"
- [hover、focus、active 状态]

响应式适配：
- 平板端：[本 section 在 768-1023px 下的布局变化]
- 移动端：[本 section 在 <768px 下的布局变化]
```

## 写作要点

- 使用视觉描述语言：尺寸、颜色、间距、字重
- 提及具体数值或范围：不说"大标题"，说"48px Bold"
- 描述层级关系：哪些元素在视觉上更突出
- 组件描述时先说外观再说内容
- 对齐方式要说清楚：左对齐、居中、右对齐
- 配图 / 插图需求要描述意境，不要只说"放个图"
- 每个 section 内联设计 token，不要写"同上"或"参见配色方案"
- 不要出现技术实现细节（不提框架、组件库、状态管理）
- 如果是 Figma 场景，可以建议 Frame 命名（如 "Hero/Desktop"、"Hero/Mobile"）和 Auto Layout 方向
