# Vibe Coding 工具 Prompt 模板参考

当目标工具是 Qoder、Cursor、Bolt、v0、Lovable 等代码生成工具时，按以下模板组织每个页面的 prompt。

## 整体方向 Prompt 模板

```
项目概述：[一句话描述产品]
目标用户：[面向谁]

技术栈：
- 框架：[React / Vue / Next.js 等]
- 样式方案：[Tailwind CSS / CSS Modules / shadcn/ui 等]
- UI 组件库：[如适用：Ant Design / Element Plus / shadcn 等]
- 状态管理：[如适用：Zustand / Pinia / Redux 等]

设计方向：
- 风格：[2-3 个关键词]
- 参考：[可选，类似 XXX 产品的风格]
- 暗色/亮色模式：[默认模式，是否支持切换]
- 响应式：[是否需要移动端适配，断点策略]

项目结构建议：
- 路由结构：[列出主要路由]
- 共享布局：[描述通用 Layout 组件]
- 全局状态：[需要全局共享的状态]
```

## 单页面 Prompt 模板

```
页面：[名称]
路由：[如 /dashboard, /users/:id]
用途：[用户来这个页面做什么]

组件结构：
[描述组件树，可以用缩进表示层级]
- PageLayout
  - Header（标题 + 操作按钮）
  - FilterBar（搜索框 + 筛选下拉 + 日期选择器）
  - DataTable（数据列表）
    - TableRow（每行的结构）
  - Pagination（分页器）

各组件说明：

[Header]
- 左侧：页面标题 "[标题]"
- 右侧：主操作按钮 "[按钮文字]"

[FilterBar]
- 搜索框：placeholder "[提示文字]"，防抖 300ms
- 筛选项：[列出各筛选条件和选项]

[DataTable]
- 列定义：
  | 列名 | 字段 | 宽度 | 对齐 | 说明 |
  | --- | --- | --- | --- | --- |
  | [名称] | name | auto | left | 可点击跳转详情 |
  | [状态] | status | 100px | center | Badge 组件，颜色映射：pending-黄, active-绿, closed-灰 |
- 支持：排序（按 [字段]）、多选、行内操作（编辑/删除）

示例数据：
[提供 JSON 格式的 3-5 条示例数据]

交互逻辑：
- 点击行 → 跳转到 /[path]/:id
- 点击删除 → 弹出确认对话框 → 调用删除接口 → 刷新列表
- 筛选变更 → 重置分页到第 1 页 → 重新请求数据

状态处理：
- 加载中：表格区域显示 Skeleton
- 空数据：居中显示空状态插画 + "[提示文字]" + 主操作按钮
- 错误：Toast 提示错误信息，保留上次数据
```

## 写作要点

- 组件结构用树形缩进，直观展示嵌套关系
- 交互用"触发 → 结果"句式，条件分支用箭头链接
- 示例数据用 JSON，方便工具直接使用
- 提到 API 时用 RESTful 风格描述（GET /api/users），不需要写完整实现
- 状态描述覆盖：加载、成功、空态、错误四种
- 表单验证直接写规则（如"邮箱格式校验"、"必填"、"最大 100 字符"）
- 响应式适配如果需要，说明关键断点（如 md:768px 以下导航收起为抽屉）
